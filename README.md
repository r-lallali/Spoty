# SpotyFusion

Un petit client Spotify en React pour en apprendre plus sur ses goûts musicaux avec une interface perso.

## Fonctionnalités

- **Stats** : top artistes, top titres et dernières écoutes, filtrables par période (4 semaines, 6 mois, all time).
- **Blindtest** : quiz musical à partir d'une de tes playlists, avec score à la fin.
- **Générateur de playlist** : recommandations basées sur tes goûts, exportables en playlist Spotify.

## Stack

React 19, TypeScript, Vite, Chakra UI, TanStack Router, Zustand.
